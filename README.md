# 🐍 Python – Projeto Final EBAC

Este repositório contém o **Projeto Final de Python** desenvolvido no curso de Ciência de Dados da **EBAC**, aplicando etapas essenciais do ciclo de análise de dados: limpeza, análise exploratória, modelagem preditiva e interpretação dos resultados.

---

## 🔍 Sobre o Projeto

O objetivo deste projeto é demonstrar, de forma prática, a aplicação dos principais conceitos de **Python para Ciência de Dados**, transformando dados brutos em informações úteis para análise e tomada de decisão.

Ao longo do projeto são exploradas técnicas de:
- preparação de dados
- visualização
- modelagem preditiva
- avaliação de modelos

---

## 🎯 Objetivos do Projeto

- 🧹 Limpeza e tratamento de dados  
- 📊 Análise exploratória com visualizações  
- 🤖 Construção de modelos de Machine Learning  
- 📈 Avaliação de métricas de desempenho  
- 🧠 Interpretação dos resultados obtidos  

---

## 🧰 Tecnologias Utilizadas

  - Pandas

## 🚀 Como Executar o Projeto Localmente

### 🔹 Pré-requisitos

- Python 3.7 ou superior  
- Git instalado  

---

### 🛠️ Instalação

1. Clone o repositório:

```bash
git clone https://github.com/JoaoPauloCosta812/Python-Projeto-Final-EBAC.git
```

2. Acesse a pasta do projeto:

```bash
cd Python-Projeto-Final-EBAC
```

3. (Opcional) Crie um ambiente virtual:

```bash
python -m venv venv
```

Ative o ambiente virtual:

**Windows (PowerShell):**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

4. Instale as dependências:

```bash
pip install -r requirements.txt
```

---

## ▶️ Executando o Projeto

Caso exista um script principal:

```bash
python main.py
```

Caso o projeto utilize notebooks, abra o arquivo `.ipynb` no Jupyter Notebook ou no VS Code.
